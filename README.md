# Synctune Consulting

A single-page company branch site for
[consulting.synctune.it](https://consulting.synctune.it).
Customer work stays confidential. Plain HTML and CSS, with local assets and
fonts. No JavaScript, dependencies, install command or build step.

- [Preview and Pages deployment](docs/deployment.md)
- [Content, confidentiality and brand assets](docs/maintenance.md)

Site source lives at the repository root. GitHub Actions packages and deploys
site changes on `main`, with no install or build step. Configure Pages to use
**GitHub Actions** first; see the deployment docs.
